# Time-Alarm-App
This is a Multi-Task time app. Timer, Alarm, World Time, Chronometer...


*Writed on Python 3.14*

--Used Librarys--
-Pyqt5
-Os
-Sys
-ZoneInfo
-Datetime


**If you are going to use the application, place both the `clock-app.py` 
file and the `alarm_sound.wav` file into a single folder, and run it from there.**
